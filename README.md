# Palindrome Checker (Java)

## About the Project
Palindrome Checker is a menu-driven Java console application that checks whether a given string or number is a palindrome.

A palindrome is a word or number that remains the same when reversed.

This project was developed as part of the Java Programming Internship at Veda Technology.

## Features
- Check whether a string is a palindrome.
- Check whether a number is a palindrome.
- Case-insensitive string checking.
- Separate methods for string and number checking.
- User-friendly console menu.

## Technologies Used

- IntelliJ IDEA

- Conditional Statements

## How to Run
1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Open `Main.java`.
4. Run the Main class.
5. Select an option from the menu.
6. Enter a string or number to check.

## Application Menu

1. Check String
2. Check Number

## Example Output

**String Example:**
```text
Enter a string: MADAM
It is a Palindrome!
```

**Number Example:**
```text
Enter a number: 121
It is a Palindrome!
```

**Non-Palindrome Example:**
```text
Enter a number: 123
It is NOT a Palindrome!
```
